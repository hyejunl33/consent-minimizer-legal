Don't Track Me Privacy Policy

Effective: 2026-11-08 · Version 0.2.0 · Korean name: 내정보 가져가지 말라고

Don't Track Me (the "extension") rejects cookie banners and helps you keep only the required consents on signup forms. This policy explains what the extension handles, where it stores it, and how you can delete it.

1. Summary

  • No account, no login.
  • No developer server, no third-party server, no external communication.
  • Page content, typed input, and personal data are never uploaded.
  • The extension does not read or modify browser cookies. It does not request the cookies permission.
  • All records stay in your browser (chrome.storage.local).
  • Use "Delete all records" in the popup to erase them at any time. Uninstalling also deletes them.

2. What the extension does

On pages you visit, the extension looks for cookie banners and signup consent controls and acts as follows.

  • Clicks a reject/necessary-only button only when it is clearly identified.
  • Checks required signup consents and unchecks optional consents.
  • Does not touch the master "agree to all" control.
  • Never clicks "accept all" or "agree to all".
  • Never submits a form.
  • Does nothing when confidence is low.
  • Stops both modules during login, payment, checkout, and identity-verification flows.

Checking required consents is a convenience for the signup flow. You remain responsible for reviewing the terms, deciding whether to sign up, and giving final consent.

3. Data stored

  • Site host (for example example.com; no path or query string)
  • Action type (cookie rejected, required checked, optional unchecked, skipped, failed) and timestamp
  • Control label shown by the page (for example "Marketing consent")
  • Classification: consent category, confidence, and source (rule or heuristic)
  • Per-site settings: whether the site is paused, and the last cookie-processing date
  • Aggregate counters derived from those records
  • Install time

This data does not include account identifiers, email addresses, names, cookie values, or typed input. A control label is copied from the page, so in rare cases a label itself could contain personal data.

4. Retention

  • Recent activity keeps the latest 500 records; older records are removed automatically.
  • Per-site settings and aggregate counters remain until you delete all records or uninstall the extension.

5. Deletion

Use Delete all records in the popup. A confirmation appears, and data is deleted only after you choose Yes.

  • Deleted: activity records, aggregate counters, per-site settings (pause and daily guard), and install time.
  • The deletion clears the extension's storage in one operation; it does not leave a partial copy.
  • The extension keeps working after deletion and will store new activity.

Uninstalling the extension also deletes the same data from your browser.

6. Third parties and external transmission

Stored data is not provided, sold, or shared with third parties. The extension contains no analytics, advertising, or remote-configuration tooling and does not communicate with external servers. The bundled @duckduckgo/autoconsent library runs only inside the page and does not send data out. See THIRD_PARTY_NOTICES.md for details.

7. Permissions

  • storage: store the records and settings above in chrome.storage.local.
  • <all_urls> (host permission): find and handle cookie banners and signup consents on any site you visit. Page content is never sent out.

8. Children

The extension is not directed to children and does not collect information about children.

9. Changes

If this policy changes, we update this page and the effective date first. Material changes to data handling are announced in the extension update notes.
